# Fanelesibonge Hlebani — Personal Portfolio

A personal portfolio website showcasing my background, projects, education, experience, certifications, and technical skills as a software developer.

The portfolio is built with React, TypeScript, TanStack Start, Vite, and Tailwind CSS.

## Live Portfolio

Add your deployed link here once Vercel is live:

`(https://faneleh.vercel.app/)`

## About the Project

This portfolio was created to present my work and technical journey in a clear, professional way.

It includes information about:

- My software development background
- Full-stack development experience
- Technical skills and tools
- Education and certifications
- Personal and academic projects
- Contact information
- GitHub and LinkedIn profiles

The project was originally scaffolded using an AI-assisted development platform, but it has since been refactored to remove platform-specific runtime dependencies and unnecessary generated components.

The source code is now maintained independently through Git and GitHub.

## Tech Stack

- React 19
- TypeScript
- TanStack Start
- TanStack Router
- TanStack Query
- Vite
- Tailwind CSS
- Lucide React
- Nitro
